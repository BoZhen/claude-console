# Panzoom

Vendored `@panzoom/panzoom` 4.6.2, used for wheel zoom, pinch zoom and drag panning
in the picture viewer (a picture in the chat, opened over it). Served locally, without
a runtime CDN dependency.

- Upstream: https://github.com/timmywil/panzoom
- Package: https://registry.npmjs.org/@panzoom/panzoom/-/panzoom-4.6.2.tgz
- License: MIT, preserved in `LICENSE`.

`panzoom.min.js` is copied unchanged from the package's `dist/` directory.
